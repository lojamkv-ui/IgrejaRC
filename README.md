## Funcionalidades

- Login com sessão e logout
- **Usuários**: registro, vínculo a membros, login por pessoa
- **Permissões por perfil** (menu e ações)
- Membros, famílias, histórico, visitantes
- Departamentos e cargos configuráveis
- Agenda de cultos e escalas
- Relatórios com exportação CSV

## Como criar login para um membro

1. Entre como Pastor ou Admin  
2. Abra a **ficha do membro** → botão **Criar login**  
   **ou** vá em **Usuários** → **+ Novo Usuário** e vincule o membro
